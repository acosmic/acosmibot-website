AI Integration

Mention Acosmibot for documentation-grounded conversation, live Discord context, native tools, summaries, search, memory, and creative actions controlled by your server.

Overview

Acosmibot's AI integration gives your server a conversational AI assistant that lives right inside Discord. Members interact with it naturally by mentioning the bot, while server managers control whether it responds, its personality on eligible plans, ambient behavior, and channel access. Subscription-tier and globally managed limits remain enforced by Acosmibot.

Key Features

  • Responds to any message that mentions the bot
  • Uses recent Discord channel history for context
  • Built-in 3-second per-user cooldown to prevent spam
  • Daily and monthly usage limits set by the active subscription tier
  • Neutral, safety-screened answers with structured personas on Pro or Max
  • Saved personalities — switch the bot's persona with /ai-admin personality or from the dashboard (Pro or Max)
  • Per-user memories extracted from screened conversation, with private review and clear controls
  • Permission-checked Channel Summaries for the current or one selected same-server channel (Pro or Max)
  • Native tools for live Discord facts, statistics, reminders, weather, Acosmibot help, web results, and World of Warcraft
  • Moderated web-image search that uploads a real Discord attachment (Pro or Max)
  • Ambient replies — the AI can occasionally chime into conversation unprompted (Pro or Max)
  • Restrict AI responses to specific channels
  • Provider-neutral chat, image, and vision support selected through Acosmibot's owner configuration
  • Policy-gated prepaid AI Credits for eligible foreground overage after included quota
  • Explicit personal text chat in Discord DMs when DM spending is enabled and opted in

Live Discord Data and Native Tools

Acosmibot exposes only the tools allowed by the server's plan, settings, channel, and request. It can ground answers in current channels, roles, events, server facts, permission-safe member information, activity and game statistics, weather, reminders, official Acosmibot documentation, web results, and supported Blizzard character data instead of guessing from model memory.

Role permission answers

Explicit questions about a role's permissions or which roles grant a permission read the live base server-role flags. Results include @everyone and managed roles and distinguish a direct permission grant from effective access through Administrator. Channel overwrites and a member's other roles can change that member's final permissions, so this is not presented as a complete member permission audit.

Pro and Max managers can independently enable or disable each model-facing tool in AI settings. A tool switch affects natural-language AI use only and does not disable the corresponding slash command. Final text still crosses Acosmibot's output-screening, trusted-link, and Discord-mention boundaries before delivery.

Channel Summaries

On Pro and Max, use /ai summary or mention Acosmibot and ask for a TL;DR, catch-up, or summary. The request can read the current channel or one explicitly selected same-server message channel. Both the requester and Acosmibot must be able to view that target and read its message history before any history is loaded.

  • Choose today, yesterday, the last 1, 3, 6, 12, or 24 hours, or one recent calendar date.
  • Unsupported rolling durations snap to the nearest supported window, and the answer names the period actually read.
  • At most the latest 500 eligible human messages and 120,000 source characters are used; bots and webhooks are excluded.
  • Source text is treated as untrusted data and is not persisted as a transcript.
  • Pro includes 100 and Max 300 fresh summaries per allowance month. A matching result may be reused for ten minutes without another summary unit.
  • Mention-chat summaries also use one normal chat request; direct /ai summary use does not. AI Credits cannot unlock or bypass the summary allowance.

Live World of Warcraft Tool

Mention Acosmibot and ask for a named World of Warcraft character's profile, PvP record, or PvE progress. Include the character, realm, region, and exact game product, such as @Acosmibot look up Biitti on Spineshatter EU Anniversary. When “Classic” is ambiguous, Acosmibot asks whether you mean progression, Era/Hardcore, or Anniversary instead of searching the wrong profile namespace.

Grounded Blizzard results

  • Profile requests receive the same visual character card and requester-only Overview, Gear, and Talents pages as /wow profile.
  • A missing full-body render or card-service problem falls back to the complete profile embed.
  • PvP and PvE answers use only the sections Blizzard returns; Classic results may be partial and Mythic+ is Retail-only.
  • The WoW tool is available on every plan with normal foreground AI chat, can be disabled by a server manager, and is never used for ambient replies.

See the World of Warcraft character guide for supported products, regions, commands, data coverage, and troubleshooting.

Web Image Search

On Pro and Max servers with image search enabled, ask Acosmibot to find, show, or post an existing picture. Pro includes 50 and Max 100 successfully delivered web-image searches per allowance month. Each picture requested uses one image-search unit, and the containing mention also uses its normal single chat request.

Acosmibot searches with Exa, filters obvious placeholders, checks that the requested subject is visibly present and usable, moderates the candidate, and uploads one normalized image as a real Discord attachment. Failed candidates do not consume delivered-use quota. Ask for the source explicitly if you also want the source-page link. Requests to create new artwork use image generation; questions about an attachment or supported Discord sticker use image analysis.

AI Credits and DMs

Included daily and monthly quota is always checked first. If the server enables paid overage, a request may use the guild wallet and then a member's personal wallet only when the server policy, member policy, and per-guild consent all allow it. A request uses one complete wallet; credits are never split between wallets.

Controlled spending

  • AI Credits are prepaid service capacity, separate from the Acosmicoins economy currency.
  • Purchased credits do not expire under current terms and cannot be transferred; promotional credits may have a stated expiry.
  • Ambient and autonomous replies never spend AI Credits.
  • Manage personal balance, consent, and guardrails at AI Credits; server administrators manage the guild pool in the server Billing page.

Explicit text messages sent to Acosmibot in a Discord DM use a personal-only context. DMs do not load a guild's memory, personality, roster, tools, subscription quota, or guild wallet. DM chat spending is independently controlled and uses the personal wallet; paid DM image and vision funding are not currently live.

How It Works

1

Confirm Where AI May Respond

Basic chat defaults on. Server managers can opt out or restore it with /ai-admin disable and /ai-admin enable, then choose whether mentions are allowed everywhere or only in selected channels.

2

Members Mention the Bot

Any member can start a conversation simply by mentioning the bot in a message — no slash command required. The bot reads the recent message history in that channel to maintain context across a conversation.

3

Context is Maintained Automatically

The bot reads recent Discord channel history when it is mentioned, then sends the relevant recent messages as conversation context.

4

Rate Limits Keep Things Running Smoothly

A built-in 3-second cooldown per user prevents rapid-fire spam. Basic daily and monthly limits come from the active subscription tier and Acosmibot's global configuration; server managers cannot raise or remove them.

Commands

Enable AI responses for the server. Requires Manage Server permission. Once enabled, the bot will respond to mentions in all permitted channels.

Example:

/ai-admin enable
/ai-admin disable
Disable AI responses for the server. The bot will stop responding to mentions until re-enabled. Existing configuration settings are preserved.

Example:

/ai-admin disable
/ai status
Post the server's daily and monthly chat usage, monthly renewal time, summary, included image, analysis, and web-image-search allowances, paid-image counts by funding source, shared server AI Credit balance, ambient toggles, and active personality. Personal wallet balances remain private to /ai credits.

Example:

/ai status
/ai summary [period] [date] [channel]
Create a bounded summary of the current channel or one selected same-server channel after requester and bot permission checks. Pro or Max feature.

Example:

/ai summary period:Last 6 hours channel:#github
/ai credits

Example:

/ai credits

Manage the server's AI personality. list shows saved personalities, current shows the active one, set switches to a saved personality, and reset returns to the default. Personalities are created and edited in the dashboard's AI settings. Pro or Max feature.

Example:

/ai-admin personality set name:Pirate
/ai memory <list|clear>
Review or clear what the AI learned from conversation about you in this server. Members cannot add memory entries manually. list shows your saved memories, and clear makes the AI forget everything about you here. Pro or Max feature.

Example:

/ai memory list
/ai style <shop|active|persona|trait>
Browse manager-published full personas and compatible traits, see active temporary effects, or spend the listed Acosmicoins to activate one. A rejected or conflicting purchase spends nothing. Pro or Max server feature when the marketplace is enabled.

Example:

/ai style shop

Control whether the AI occasionally chimes into conversation without being mentioned, how often, and whether up to 25% of ambient replies may generate a meme image. Requires Manage Server permission. Pro or Max feature.

Generate an image using the configured AI image provider based on your text prompt. Pro or Max feature — image generation uses the server's current quota and any enabled paid-overage policy.

/ai image prompt:a futuristic city at night with neon lights

Analyze an attached image using the configured AI vision provider and receive a detailed description or answer questions about it. Pro or Max feature.

Channel Restrictions

By default, the bot can respond to mentions in any channel. You can restrict AI responses to specific channels so the bot only engages where you want it to — for example, a dedicated #ask-ai channel.

Setting Up Channel Restrictions

  • Channel restrictions are configured through the /server dashboard
  • Add one or more allowed channels — the bot will ignore mentions outside of them
  • To remove restrictions and allow all channels, clear the allowed-channels list
  • The bot will silently ignore mentions in non-permitted channels (no error message)

Structured Personalities and Tool Controls

Pro and Max managers customize presentation from the server dashboard under AI settings or switch saved personalities with /ai-admin personality. A structured persona is built from bounded identity fields, voice facets, catchphrases, motifs, and terms of address. Older free-form personality prompts remain visible only for migration and are not executed.

What personality can and cannot change

  • Personality changes the wording and presentation of a finished answer.
  • It cannot grant Discord permissions, change verified facts, select unavailable tools, override safety, or bypass quotas.
  • Managers can publish selected full personas or category-slotted traits with an Acosmicoin price and duration.
  • Traits from different categories can compose up to the configured limit; conflicting categories and full-persona overlaps are rejected without spending.
  • Each model-facing AI tool has its own switch. Disabling AI tool use does not disable the tool's normal slash command.

Troubleshooting

Q: The bot isn't responding when I mention it

A: Check that AI is enabled with /ai status. If channel restrictions are configured, confirm you're mentioning the bot in an allowed channel. Also verify the daily usage limit hasn't been reached.

Q: The AI seems to have forgotten our earlier conversation

A: Context comes from recent channel messages. If the conversation has moved on or the relevant details are outside the recent message window, mention the details again.

Q: How do I stop the AI from responding in a specific channel without restricting all channels?

A: Set up a channel allow-list in the dashboard that includes only the channels where you want the bot to respond. Any channel not on the list will be ignored.

Q: The bot says the daily limit has been reached

A: The daily interaction counter resets at midnight UTC. Basic daily and monthly limits come from the active subscription tier and Acosmibot's global configuration; server managers cannot raise or remove them. If paid overage is enabled, the request still needs an allowed operation, a full wallet reservation, and any required member consent. Use /ai status to see the monthly renewal time.

Q: Why did a paid AI request not use my personal balance?

A: Personal guild fallback requires all three keys: the server must allow personal fallback, your global guild-spending switch must be on, and you must opt in for that guild. The request also has to fit your caps and the server's operation policy. Check AI Credits for your guardrails.
