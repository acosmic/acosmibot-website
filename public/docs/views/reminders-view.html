Reminders

Never forget anything — set a reminder and Acosmibot will DM you the moment the time arrives.

Overview

The reminder system lets anyone schedule a personal message to be delivered at a future time. Set reminders with /reminder in any server channel where Acosmibot is active or in a DM with Acosmibot, or ask Acosmibot in a server. Reminders are sent as a direct message from the bot so they reach you wherever you are, even if you've left the server in the meantime.

Key Features

  • Set reminders up to 5 years in the future
  • Use a duration like 2h30m or a date and time like tomorrow 9am or friday 3pm Budapest time
  • Works in server channels and in DMs with Acosmibot
  • Create, view, and cancel reminders by asking Acosmibot in natural language, in any language
  • Cancel individual reminders by ID before they fire
  • Delivered as a DM with a link back to where you set it
  • Available on every plan; /reminder has no usage limit

Ask Acosmibot Naturally

Mention Acosmibot in a server and ask it to manage your reminders conversationally, in English or any other language. AI-created reminders are saved in the same system as slash-command reminders, appear in /reminder list, and follow the same DM delivery process.

Examples:

@Acosmibot remind me tomorrow at 9am to submit the report @Acosmibot recuérdame en 30 minutos sacar la basura @Acosmibot what reminders do I have? @Acosmibot cancel my report reminder

Where AI Reminders Work

  • Ask in a server channel where AI chat is on. Asking Acosmibot in a DM does not create reminders — use /reminder set there instead.
  • Each request counts as an AI chat reply toward the server's daily and monthly AI allowance (see Subscription Plans). /reminder commands never use that allowance.
  • Asked in a server, Acosmibot lists and cancels your reminders from that server.
  • Server admins can turn the reminder tool off in the server's AI settings.

Commands

/reminder set <when> <message>
Set a reminder for a future time. when can be a duration or a date and time (see Time Format Reference below). Works in server channels and in DMs with Acosmibot. The bot will DM you with your message when the time arrives.

Examples:

/reminder set 30m Check the oven /reminder set 2h30m Team meeting starts soon /reminder set tomorrow 9am Take out the trash /reminder set friday 3pm Budapest time Raid night
/reminder list
View your active reminders, including each reminder's ID, message, and when it fires. In a server it shows the reminders you set in that server; in a DM with Acosmibot it shows all of your reminders.

Example:

/reminder list
/reminder cancel <id>
Cancel one of your active reminders before it fires, from any server or a DM. Use /reminder list to find the ID of the reminder you want to remove.

Example:

/reminder cancel 42

Time Format Reference

when is either a duration from now or a date and time. The English formats below are read directly. Anything else, including a time written in another language, is first rewritten into one of these formats by AI; check the time on the confirmation.

Durations

Unit Accepted Formats Example Input
Seconds s, sec, seconds 90s
Minutes m, min, minutes 5m, 15min
Hours h, hr, hours 2h, 3hr
Days d, days 1d, 7d
Weeks w, week, weeks 2w, 4week
Years (365 days) y, yr, years 1y, 2yr
Combined Multiple units chained 2h30m, 2 hours 30 minutes, in 45 minutes

Combining Time Units

  • 2h30m — 2 hours and 30 minutes from now
  • 1d12h — 1 day and 12 hours from now
  • 1w2d — 1 week and 2 days from now
  • 1y2w — 1 year and 2 weeks from now

No Months

m always means minutes, so 1y6m is one year and six minutes. Months aren't a duration unit — use weeks or a date instead.

Dates and Times

Kind Example Input Fires
Time today 3:30pm, 15:30, 9pm The next time the clock reads that time
Today, tonight, tomorrow, day after tomorrow today 5pm, tonight, tomorrow 9am, day after tomorrow 8am tonight alone is 8 PM; today, tomorrow, or day after tomorrow alone is 9 AM
Weekday friday 3pm, next friday, next week thursday 2pm The next matching day; next week means the following Monday-to-Sunday week
Date July 4, 12/25 8pm, 2026-12-25 8:00 A date with no year is the next time that date comes around; a date with no time fires at 9 AM
Exact instant 2026-12-01T14:00:00+02:00 That exact moment, regardless of time zone settings

Time Zones

  • Dates and times use the Personal timezone from acosmibot.com/settings. If you haven't set one, reminders use UTC — not the server's time zone.
  • Add a time zone to the end to use it instead: tomorrow 9am Europe/London, friday 3pm Budapest time, or 3pm New York time. Use a full IANA name or a city name.
  • Daylight saving time is handled for you. A time that is skipped or repeated when the clocks change is rejected; use an exact instant with an offset instead.
  • Durations like 30m don't depend on any time zone.
  • The confirmation shows the exact time and, for dates and times, the time zone used.

How It Works

1

Set your reminder

Run /reminder set <when> <message> in any channel where the bot is active or in a DM with Acosmibot, or mention Acosmibot in a server and ask. The bot confirms your reminder with a timestamp showing exactly when it will fire.

2

Go about your day

The bot tracks the timer in the background. You don't need to stay in the server or keep Discord open — the reminder will be waiting when you return.

3

Receive your DM

When the time arrives, Acosmibot sends you a direct message with your original reminder text, where you set it, and a link back to that message.

Limits & Notes

Things to Keep in Mind

  • Maximum reminder time is 5 years in the future
  • Reminder messages can be up to 1,000 characters
  • Reminders are personal — only you receive your own DMs
  • Make sure your DMs are open: if Acosmibot can't DM you when a reminder fires, that reminder is not retried
  • If the bot is offline when a reminder fires, it will be sent as soon as the bot comes back online

Frequently Asked Questions

Q: I didn't receive my reminder DM

A: Check that your Discord privacy settings allow DMs from bot accounts. In User Settings → Privacy & Safety, ensure "Allow direct messages from server members" is enabled, or add Acosmibot as a friend to allow DMs directly.

Q: My reminder fired at the wrong hour

A: Dates and times use your Personal timezone from acosmibot.com/settings, or UTC if you haven't set one. Set your time zone there, or add one to the reminder, such as tomorrow 9am America/Chicago.

Q: Can I set reminders in a DM with Acosmibot?

A: Yes. /reminder set, /reminder list, and /reminder cancel all work in a DM with Acosmibot, and /reminder list there shows all of your reminders. Asking Acosmibot in plain words only creates reminders in a server.

Q: Can I ask in another language?

A: Yes. When you mention Acosmibot in a server, you can ask in any language and your reminder keeps your own words. In /reminder set, a time in another language (such as en 20 minutos) is rewritten into English by AI before it is saved. That rewrite needs Acosmibot's AI to be available; English formats such as 20m or tomorrow 9am always work.

Q: Can I set multiple reminders at once?

A: Yes. You can have as many active reminders as you like. Use /reminder list to see them all listed together.

Q: Can other people see my reminders?

A: No. Your reminders are private — only you can view them with /reminder list, and only you receive the DM when they fire.

Q: What if I leave the server before my reminder fires?

A: The reminder will still be delivered to you via DM as long as the bot can message you.
