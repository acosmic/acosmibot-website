Server Branding

Set the server icon, banner, and invite background from Discord or the website, keep every version in a stored image library, and swap whole sets of custom emoji with emoji packs.

Open Server Branding →

Overview

Server Branding is available on Plus and higher to members with Manage Server. Change the server icon, banner, and invite background with the /server commands or from the Server Branding page in the website dashboard. On Pro and Max, you can also ask Acosmibot in chat: attach an image, or reply to one such as a picture Acosmibot just generated, and say "set this as the server icon", "make this our server banner", or "use this as the invite background". You can also say "remove the server banner".

Key Features

  • Set or remove the icon, banner, and invite background from an attached image or GIF
  • Automatic crop and resize: square 1024×1024 for the icon, 16:9 up to 1920×1080 for the banner and invite background
  • A confirmation card shows exactly what will be uploaded before anything changes
  • Every image is archived, so you can always switch back to a previous one
  • Emoji packs save your custom emoji as named sets you can swap in and out

Commands

/server icon
Set the server icon from an attached image or GIF, or remove it.
/server banner
Set or remove the server banner. Discord unlocks banners at Boost Level 2.
/server invite-background
Set or remove the invite background. Discord unlocks it at Boost Level 1.

Animated images and boost perks

Animated GIFs stay animated when the server has the perk: animated icons at Boost Level 1, animated banners at Boost Level 3. Otherwise the first frame is used. Discord never animates invite backgrounds. Large or long GIFs are shrunk, and frames dropped if needed, to fit Discord's size limit. Ask Acosmibot "what boost perks does this server have?" to see which ones are unlocked.

Generate and Set in One Request

On Pro and Max you can make an image and apply it in a single request, for example "generate a halloween version of our server icon, then set it as the icon". Mentioning "our server icon", "our banner", or "our invite background" uses the current one as the starting picture. You confirm the generated picture first, then a second card asks before anything changes in Discord.

Server Image Library

Every image Acosmibot sets is stored, and the image it replaces or removes is saved first, so you can always go back. Up to 25 unpinned images are kept per type; pinned images are kept forever.

  • Website: the Server Branding page shows the current icon, banner, and invite background. Upload new ones, rename, pin, download, delete, and set any stored image as current.
  • Chat (Pro and Max): ask "what stored icons do you have?" to list them, "send me the halloween one" to get the file, or "switch the server icon back to the previous one" to set an older one again. It still asks you to confirm.

Emoji Packs

Emoji packs save your server's custom emoji as named sets you can swap in and out, such as a Halloween set and a Winter set. Open Server Branding → Emoji Packs on the website and turn them on. Acosmibot first downloads every current emoji into a pack called Original. It works like any other pack, so you can edit, rename, or delete it, but it never counts toward your plan.

Building and applying packs

  • Build a pack by uploading images (PNG, JPEG, GIF, or WebP; anything over Discord's 256 KB emoji limit is shrunk), duplicating another pack, or saving what is live in Discord right now.
  • Applying a pack only changes what differs. Emoji in both packs stay put with the same ID, so old messages keep showing them.
  • Before anything is removed, any live emoji that is not saved in a pack yet is added to the pack that was live.
  • Mark emoji Always keep to leave them in place whichever pack is live. Emoji used by reaction roles, and emoji managed by an integration such as Twitch, are always kept automatically. Kept emoji still use slots, so a pack has to fit in the slots left over.

Keeping packs in sync

  • Emoji someone adds directly in Discord are saved into the live pack automatically.
  • To copy emoji between packs, drag them from Live in Discord or from one pack onto another, or use an emoji's +. Copying never changes Discord.
  • To take an emoji off the server, use its Remove from server button. It is deleted from Discord and from the live pack, and stays in any other pack that has it.

Things to Keep in Mind

  • Discord limits how fast emoji can be uploaded, so a large pack can take a while. The page shows progress, and you can leave it open or come back later.
  • Acosmibot needs Discord's Manage Expressions permission to apply a pack.
  • If the server drops to a lower plan, extra packs are kept but locked until you are back under the limit.

Troubleshooting

Q: The /server commands say the feature is not available

A: Server Branding requires Plus or higher and the Manage Server permission. Check the server's plan on its Billing page.

Q: My animated icon or banner stopped animating

A: Discord only animates icons at Boost Level 1 and banners at Boost Level 3. Below those levels Acosmibot uploads the first frame. Invite backgrounds are never animated.

Q: A pack would not apply

A: A pack has to fit in the emoji slots left after kept emoji. Mark fewer emoji as Always keep, remove unused live emoji, or trim the pack. Also confirm Acosmibot has Manage Expressions.

Q: Can I use these from chat on Plus?

A: On Plus, use the /server commands or the website. Asking Acosmibot in chat to set images or browse the library is an AI tool and requires Pro or Max.
