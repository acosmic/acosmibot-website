Included on Every Plan

Free, Plus, Pro, and Max all include these standard community features without plan-specific usage quotas:

  • Leveling, XP, ranks, and role rewards
  • Economy, banking, Credits, items, inventory, and the shop
  • Games and gambling, including slots, mines, blackjack, coinflip, deathroll, lottery, and heists
  • Server analytics and moderation logs
  • Music listening features and leaderboards
  • Giveaways and server events
  • Cross-server portals, Polymorph, reminders, and standard utility commands
  • Activity monitoring and dashboard administration controls
  • Better Social Embeds for Instagram, X/Twitter, Bluesky, TikTok, and Reddit
  • Stream alerts, custom commands, reaction roles, embeds, and AI chat within the limits below

How to Subscribe

You must own the server or have administrator permission for the server you want to upgrade.

1

Open Pricing and Sign In

Go to acosmibot.com/pricing and sign in with Discord.

2

Choose a Plan

Select monthly or annual billing for Plus, Pro, or Max, then choose Select Server.

3

Select the Server

Choose the server to upgrade. Only servers where you are the owner or an administrator are available.

4

Complete Checkout

Finish the secure Stripe checkout. Paid access activates for the selected server after checkout succeeds.

Checkout Availability

If a plan button says Coming Soon or checkout is paused, new subscriptions are not open at that moment. The Free plan remains available automatically.

Manage, Change, or Cancel

Sign in, select the subscribed server, and open Billing in its dashboard. From there you can:

  • Change between Plus, Pro, and Max or switch monthly/annual billing.
  • Open Stripe to update the payment method or view invoices.
  • Cancel at the end of the current billing period.

Plan changes may include a prorated charge or account credit. The dashboard previews the adjustment before changing an existing paid subscription.
