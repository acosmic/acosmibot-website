Introduction

Welcome to the Acosmibot Documentation

These modules walk you through setting up and using Acosmibot features to improve and customize your Discord server. Acosmibot is a feature-rich Discord bot covering server engagement, economy, moderation, streaming alerts, games, and AI.

Key Features

Acosmibot includes the following major features and commands:

Leveling System

Reward server activity with XP and automatic role progression. Members earn experience points by sending messages and level up over time. Supports customizable XP formulas (linear, quadratic, exponential), role rewards at milestones, level-up announcements, daily leaderboards, and XP multipliers. Commands: /rank, /leaderboard, /stats.

Economy and Banking

A virtual currency system using credits. Members earn credits through gambling games, lotteries, and credit transfers. The global bank lets members deposit and protect their credits across all servers. Transaction history and leaderboards track wealth over time. Commands: /balance, /give, /bank balance, /bank history, /bank deposit, /bank withdraw, /guildbank, /leaderboard.

Social Alerts — Twitch, YouTube, Kick, X

Real-time streaming notifications when your favorite streamers go live. Supports Twitch (EventSub webhooks), YouTube (PubSubHubbub), and Kick, plus paid X post alerts for original and quote posts. Streaming platforms support customizable announcements and per-streamer mentions; X Alerts uses one shared channel and an optional role mention.

Games and Gambling

A suite of credit-based gambling games integrated with the economy system: Slots (3-reel machine with customizable symbols and payouts), Lottery (server-wide jackpot drawings), Blackjack (classic card game vs the dealer), Coinflip (50/50 heads or tails), Deathroll (high-stakes dice duels between members). Commands: /games slots, /games mines, /games blackjack, /games coinflip, /games deathroll, /games rockpaperscissors, and /games 8ball. Server-wide lottery events run via /admin-start-lotto.

Moderation Logs

Automatic logging of key server events to your designated mod channels. Captures member joins and leaves (distinguishing kicks and bans from voluntary departures), deleted messages with original content, and edited messages showing before and after. Each event type can be routed to a separate channel and toggled independently. Configured through the server dashboard — no slash commands required.

AI Integration

Connects Acosmibot to a configured AI provider so members can have natural conversations by mentioning the bot. It uses recent Discord channel history for context and supports channel restrictions. Pro and Max add saved personalities, member memory, web search, ambient replies, image generation, image analysis, and live World of Warcraft character lookups. Basic daily and monthly limits come from the active subscription tier; server managers can configure lower tier-capped ambient limits. Server-management commands live under /ai-admin.

Utilities

Additional tools to enhance your server: Reaction Roles (assign roles via emoji reactions), Custom Commands (create your own slash commands with custom responses), Better Embeds (rich embedded message builder), Better Social Embeds (reliable Instagram, X/Twitter, Bluesky, TikTok, and Reddit previews), Reminders (scheduled personal or server reminders), World of Warcraft character cards, PvP records, and PvE progress through /wow or natural-language AI requests.

Chaos Features

Advanced and experimental features: Cross-Server Portals (link channels across different Discord servers), Polymorph (temporarily change member nicknames and avatars), and an opt-in Jail System (reaction ballots that apply temporary member-specific channel restrictions).

Development & Support

Acosmibot is actively developed and maintained. While we test features thoroughly, there may still be bugs or edge cases we haven't caught yet. If you run into any issues, we want to hear about them — we're committed to fixing problems, improving performance, and adding new features over time to make Acosmibot better for everyone.

The fastest way to get help is the Discord support server. For billing, privacy, or anything you'd rather not post publicly, email support@acosmibot.com.
